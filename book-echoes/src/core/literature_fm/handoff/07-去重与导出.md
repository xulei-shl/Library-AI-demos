# 07 - 去重与导出

> 覆盖：推荐历史去重、Excel 书单导出
> 路径：`theme_deduplicator.py`、`theme_exporter.py`

---

## 1. theme_deduplicator.py — `ThemeDeduplicator`

职责：避免同一/相似主题重复推荐相同书目。表 `literature_recommendation_history`（由 `db_init.init_recommendation_history_table` 创建）。

- `ThemeDeduplicator(db_path, history_table="literature_recommendation_history")`：自动建表 + 索引。
- `get_excluded_book_ids(user_input, conditions, similarity_threshold=0.8) -> Set[int]`：
  1. 精确匹配 `user_input` 的历史。
  2. `_find_similar_conditions(conditions)`：过滤条件相似度 ≥ 阈值的历史。
  3. 合并这些历史里的 `passed_book_ids` 作为排除集。
- `save_recommendation(user_input, conditions, book_ids, final_theme, vector_weight, randomness, method) -> bool`：落库本次推荐。
- `_calculate_condition_similarity / _compare_filter_conditions`：Jaccard 式字段重叠；**兼容新旧两种条件格式**（旧 `{field: [values]}`，新 `{filter_conditions:[...]}`）。

**注意**：相似度基于过滤条件重叠，不基于语义；阈值 0.8 偏高，相似主题仍可能命中。

---

## 2. theme_exporter.py — `ThemeExporter`

职责：把检索/融合结果导出为人工友好的 Excel 书单。

- `load_db_to_excel_mapping(config_path)` / `_get_default_mapping()`：DB 字段 → 中文列名的配置驱动映射。
- `ThemeExporter(output_dir, db_path, config_path)`。
- `_fetch_books_details(book_ids) -> Dict`：批量查 `books` 表的 `DOUBAN_FIELDS`。
- `export_excel(results, theme_text, conditions, output_path)`：单主题工作簿，含 `推荐结果` + `元信息` 两 sheet（分数 / 命中标签 / 来源）。
- `export_theme_batch(theme_results, output_path)`：批量工作簿，含汇总 sheet + 每主题一个 sheet + 元信息；保留 `rrf_score` / `rerank_score`。
- 辅助：`_parse_tags / _get_match_tags / _get_source_label / _generate_filename`。
- 来源标签区分：向量 / 标签 / 混合（`sources`）。

---

## 3. 交接要点
- "某本书怎么没被推荐"首查 `literature_recommendation_history` 是否被去重排除。
- 导出列名与映射在 `_get_default_mapping` / 配置文件；加列先改映射再改取数。
- 去重器对条件格式的向后兼容逻辑较脆弱，新增条件结构时务必同步 `_compare_filter_conditions`。
