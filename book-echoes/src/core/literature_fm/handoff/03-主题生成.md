# 03 - 主题生成

> 路径：`src/core/literature_fm/theme_generator.py`
> 对应 Phase：Phase 2.5（文学策划主题生成）

---

## 1. 职责

`ThemeGenerator` 用 LLM 生成"文学策划主题"，并把结果同时导出为 **机器可读 JSON** 和 **人工可读 Excel**。生成的主题是下游 `query_translator` 的输入。

---

## 2. 主题数据结构

每个主题：
```json
{
  "theme_name":   "冬夜独处：暖灯下的一杯热可可",
  "slogan":       "当城市睡去，书页替你醒着",
  "description":  "为那些在寒夜里渴望安静陪伴的读者……",
  "target_vibe":  "温暖、私密、缓慢"
}
```

---

## 3. ThemeGenerator

- `ThemeGenerator(config=None)`：内部用 `UnifiedLLMClient`。
- `generate_themes(direction="", count=5) -> Dict`：
  - 返回 `{success, themes, output_file, count, error}`。
  - 受 `theme_generation.enabled` 控制（CLI 会先检查）。
- `_build_user_prompt(direction, count)`：注入 few-shot 的 JSON 示例，约束输出结构。
- `_parse_response(resp) -> List[Dict]`：解析；若 LLM 返回单个对象则包成列表。
- `_validate_themes(themes)`：校验 4 个必填字段。
- `_save_themes(themes, direction) -> str`：写 JSON + 中文表头、设定列宽的 Excel；文件名带时间戳与 direction 安全后缀。

**输入**：`direction`（策划方向/关键词，可空）、`count`。
**输出**：`runtime/outputs/...` 下的 JSON 与 Excel；返回 dict。

---

## 4. 交接要点
- 主题生成的"质量"直接影响后续检索——`description` 越具体，向量检索越准。
- 生成的 Excel 直接可作为 `query_translator` 的输入（`query-trans --excel`）。
- 仅生成主题，不做检索；检索由 `query_translator` + `generate_theme_shelf` 完成。
