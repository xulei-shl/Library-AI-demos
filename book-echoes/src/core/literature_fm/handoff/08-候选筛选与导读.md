# 08 - 候选筛选与导读

> 覆盖：候选书单 LLM 二次筛选、卷首导读生成
> 路径：`candidate_filter.py`、`prologue_generator.py`
> 对应 Phase：Phase 3.5 / Phase 3.6

---

## 1. candidate_filter.py — `CandidateFilter`

职责：读取 `theme_exporter` 产出的候选 Excel，**分组**送 LLM 做人工视角的"初评"，结果写回同一 Excel。

- `CandidateFilter(config)`：要求配置里有 `excel_fields.book_fields` 映射（缺失会报错，作为配置正确性校验）。
- `filter_from_excel(excel_path) -> Dict`：返回 `{success, processed, passed, groups, output_file, error}`。
- `_read_theme_info(excel_path)`：从 `主题汇总` sheet 读主题信息。
- `_read_candidate_sheets(...)`：读候选 sheet（排除 `主题汇总` / `元信息`）。
- `_group_candidates(candidates)`：随机洗牌 + 按 `group_size` 切块（带 seed，可复现）。
- `_call_llm_filter(theme, group, idx)`：给每组逐本加 `初评结果 / 初评分数 / 初评理由`。
- `_parse_llm_response`：JSON + 代码块围栏兜底解析。
- `_write_results_to_excel`：用 openpyxl **原地追加列**：初评结果 / 初评分数 / 初评理由 / 人工评选 / 人工推荐语 / 终评理由。

**输入**：候选 Excel。**输出**：同一 Excel 增加初评列；统计 dict。

---

## 2. prologue_generator.py — `PrologueGenerator`

职责：基于人工已通过的图书，生成一段"卷首导读" Markdown。

- `PrologueGenerator(config)`：要求 `excel_fields.book_fields`。
- `generate_from_excel(excel_path) -> Dict`：`{success, book_count, output_file, error}`。
- `_read_approved_books(...)`：跨所有候选 sheet，筛选 `approval_column == approval_value`（默认 `人工评选` == `通过`）。
- `_build_user_prompt(theme, books)` / `_call_llm_generate`（task `literary_writer`，**返回纯文本**，不解析 JSON）。
- `_save_to_markdown(content, excel_path, theme_name)`：写带时间戳的 `.md`。

**输入**：含人工评选结果的 Excel。**输出**：Markdown 导读文件。

---

## 3. 交接要点
- 两步都**就地修改/依赖 Excel 产物**，是流水线的"人审环节"：先 `candidate_filter` 初评，人工在 Excel 填"人工评选/推荐语"，再 `prologue_generator` 生成导读。
- `CandidateFilter` 失败的行会被标 `未通过`，不会中断整批。
- `prologue_generator` 只读纯文本输出，若未来要求结构化（如分章节）需改 `_call_llm_generate` 与保存逻辑。
